# KILN Research

Use this skill before broad KILN integration or major design decisions.

Research should compare relevant precedents such as MSBuild, Cargo, Bazel,
GitHub Actions, SLSA, OPA policy handoff, package manifests, and conformance
test systems. Summaries must separate evidence from recommendation and state
which KILN contract, fixture, or validation command should change.
